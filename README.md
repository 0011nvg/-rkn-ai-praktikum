# Практикум по использованию ИИ в преподавании РКН

Автор: Науменко Виктория Геннадьевна.

Статический сайт без внешних зависимостей. Все ресурсы находятся в `docs/`.

## Просмотр

Откройте `docs/index.html` или запустите `python -m http.server 8000 --directory dist`.

## Публикация GitHub Pages

Загрузите папку `docs/` и README.md в отдельный публичный репозиторий. В Settings → Pages выберите Deploy from a branch, ветку main и папку /docs. Пути относительные и поддерживают адрес проекта в подпапке.

## Обновление

Редактируйте `docs/index.html`, `docs/style.css`, `docs/app.js`, `docs/tools-data.js`. Коммит в main обновляет сайт. Не загружайте служебные файлы, исходные документы проекта или данные учеников.

## Проверка

`node --check docs/app.js` и `node --check docs/tools-data.js` проверяют синтаксис. Дополнительно проверяйте браузер: фильтры, конструктор, избранное, прогресс, клавиатуру и печать.

Черновики конструктора хранятся только в памяти вкладки. Прогресс и избранное — в localStorage. Данные не отправляются в ИИ. Изображения и лицензии перечислены в `photos.json` и на странице. Справочные сведения о сервисах проверены по официальным источникам 25.10.2026; доступ из российских сетей не тестировался.
